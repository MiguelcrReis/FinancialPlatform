# Planejamentos

Esta pasta guarda planejamentos tecnicos do FinancialPlatform antes da implementacao.

Use estes documentos para registrar objetivo, decisoes, escopo, passos de implementacao, testes e riscos relevantes de uma mudanca. A ideia e manter um historico simples do que foi decidido sem criar uma estrutura pesada de ADR neste momento.

## Convencao de nomes

Salve cada planejamento como Markdown usando o formato:

```text
YYYY-MM-DD-nome-curto-do-plano.md
```

Exemplo:

```text
2026-05-15-correlation-id-distribuido.md
```
